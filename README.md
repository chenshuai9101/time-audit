# Time Audit ⏱️

> 本地大模型驱动的工作行为分析中间件 — 把屏幕录制变成可自动化的工作模式

[![License](https://img.shields.io/badge/license-MIT-blue)](LICENSE)

## 概述

Local-LLM-driven behavior analysis middleware。将屏幕录制转化为 LLM 可消化的会话片段，找出可自动化的工作模式。

## 核心功能

- **📹 屏幕录制分析** — 自动切片和标注工作片段
- **🤖 本地LLM处理** — 隐私优先，数据不出本地
- **🔍 模式识别** — 发现重复性工作和自动化机会
- **📊 效率报告** — 生成时间分配和效率分析报告
